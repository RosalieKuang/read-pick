# Privacy / 隐私说明

**English**

Read & Pick has no server of its own and collects no data.

- Your API key, settings and saved words are stored only in your browser's local extension storage (`chrome.storage.local`).
- When you click "译" (translate) or "挑词" (pick words), the text of that paragraph or article, plus the page title, is sent to the API endpoint **you** configured in Settings. Nothing is sent anywhere else.
- No analytics, no tracking, no third-party scripts.
- The extension asks for access to all websites only so it can show its buttons and highlights on whatever page you are reading.

What happens to text after it reaches your API provider is governed by that provider's own privacy policy.

**中文**

Read & Pick 没有自己的服务器，不收集任何数据。

- API key、设置和收藏的单词只保存在你浏览器本地的插件存储里。
- 你点“译”或“挑词”时，那一段或整篇文章的文字连同网页标题，会发送到**你在设置页填写的那个 API 地址**，不会发给其他任何地方。
- 没有统计、没有追踪、没有第三方脚本。
- 插件申请“读取所有网站”的权限，只是为了在你阅读的网页上显示按钮和划线。

文字发送到你的 API 服务商之后如何处理，以该服务商自己的隐私政策为准。
