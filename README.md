# Read & Pick 读词助手

一个给英语学习者用的 Chrome 插件。读英文文章时页面只显示英文，哪段看不懂，点一下就能看那一段的中文。它还能帮你从文章里挑出值得学的词，告诉你哪些该学着用、哪些认识就够了。

## 起因：chips 被翻成了薯片

有一天我在读《经济学人》，有篇文章讲美国内阁为芯片的事吵成一团，标题里有个 chips。翻译插件把它翻成了"薯片"，于是我看到的标题是"一场关于薯片的争论正在搅乱特朗普的内阁"。

我笑完一查，那个插件默认用的是谷歌翻译，一句一句硬翻，根本不看整篇讲的是什么。想换成效果更好的 AI 翻译，又得开会员。可我手上本来就有大模型的 API，自己调一次也就几分钱，没必要为这个多交一份钱。

再加上我发现，中英对照摆满一整页的时候，眼睛会不自觉地往中文那行跑，一篇文章读下来，英文反而没怎么进脑子。

所以我干脆自己做了一个：

- 用自己的 API key，翻译时让模型把标题和上一段一起看，chips 就不会再变成薯片。
- 默认只显示英文，真卡住了才看中文。
- 挑词的时候不光看词难不难，更看我该不该主动用它。很多词我其实认识，但一张嘴、一下笔就想不起来，或者用错了场合。

## 它能干什么

**点一段，看一段。** 每段左边有个小小的"译"字，点一下这段下面出中文，再点就收起来。

**一键挑词。** 点浮窗里的"挑词"，它会把整篇文章交给大模型，挑出十几二十个值得学的词，直接在原文里划线：

- 粉色实线：值得学着主动用
- 蓝色虚线：认识就行
- 灰色点线：专有名词或术语，看懂就好

**点划线的词，弹出一张词卡。** 卡上有英文解释、中文意思、常用搭配，还有一句能整句背下来的例句。如果这个词偏书面，它会告诉你口语里一般怎么说；如果这个词容易读偏（一词多义、俚语、长得像但意思不一样），也会单独提醒你。

每个词还会标上它适合在哪儿用：🗣 说话能用、✍️ 只适合写、👀 认识就行、🗣✍️ 两边都行、🗣👀 俚语。

**收藏、导出。** 喜欢的词点"收藏"，它会顺手把原句和文章链接一起存下来。攒够了一键导出成 Markdown，直接丢进 Notion 或 Obsidian。

**浮窗不挡字。** 浮窗可以拖到任何地方，松手自动贴边，嫌占地方就缩成一个小圆点。位置它会记住。

真读不动的时候，按 Option（Windows 是 Alt）+ Shift + A，整篇的中文一次全出来，再按一次全收起。

## 怎么装

还没上 Chrome 应用商店，要手动装一下，两分钟的事：

1. 点这个页面右边的 **Releases**，下载最新的 `read-pick.zip`，解压。
2. 在 Chrome 地址栏输入 `chrome://extensions`，回车。
3. 打开右上角的 **开发者模式**。
4. 点 **加载已解压的扩展程序**，选刚才解压出来的 `read-pick` 文件夹。
5. 它会自动弹出设置页，填好 API（看下一节），点"测试连接"，显示"连上了"就可以用了。

两个小提醒：解压出来的文件夹别删也别挪，Chrome 每次都从那儿读；如果你还开着别的网页翻译插件，先关掉，两个一起开会打架。

## 你需要一个自己的 API key

这个插件没有服务器，翻译和挑词都是用你自己的 key 去调大模型。只要是兼容 OpenAI 格式的接口都能用。

| 用哪家 | 接口地址 | 模型 |
|---|---|---|
| DeepSeek（便宜，中英文效果好） | `https://api.deepseek.com` | `deepseek-chat` |
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` 等 |
| 其他兼容的服务 | 服务商给的地址 | 服务商给的模型名 |

**DeepSeek 的 key 怎么拿：** 去 DeepSeek 开放平台注册登录，充几块钱（能用很久），在 API keys 那里新建一个，把 `sk-` 开头的那一串复制到设置页。这串 key 只显示一次，记得先存好。

**要花多少钱：** 我用 DeepSeek，单段翻译基本可以忽略不计，整篇挑词一次也就几分钱。具体以服务商当时的价格为准。

## 让它更懂你

设置页里有一栏"学习者说明"，挑词的时候会原样发给模型。你在里面写清楚自己什么水平、在准备什么考试、做什么工作、平时喜欢干什么，它挑的词会更贴你，例句也会往你的生活里造。比如：

```
C1 English reader (Chinese native), target IELTS 7.5. Weak spot is speaking.
Works in marketing. Hobbies: hiking, coffee, travel in Japan.
```

用英文写，效果会稳一点。

## 你的数据去哪了

- API key 只存在你自己的浏览器里，哪儿也不传。
- 你点"译"或者"挑词"的时候，那段（或那篇）文字会发给你自己填的那个 API 地址。除此之外，不发给任何人，我这边也收不到任何东西。
- 插件要"读取所有网站"的权限，是因为它得在你读的任何网页上显示按钮和划线，没别的用途。

想看完整说明，见 [PRIVACY.md](PRIVACY.md)。

## 想自己改？

全是普通的 JavaScript，不用编译。改完去 `chrome://extensions` 点一下刷新就生效。

| 文件 | 负责什么 |
|---|---|
| `background.js` | 调 API；翻译和挑词的 prompt 都在这儿 |
| `content.js` | 页面上看得到的一切："译"按钮、划线、词卡、浮窗 |
| `content.css` | 页面上的样式和颜色 |
| `popup.html` / `popup.js` | 点工具栏图标弹出来的那个小窗：收藏列表、导出 |
| `options.html` / `options.js` | 设置页 |

想换挑词的标准，改 `background.js` 里 `vocab()` 那段 prompt 最快；想换导出的格式，改 `popup.js` 里的 `toMarkdown()`。

## 目前还做不到的

- 如果一个短语中间夹着链接，有时候划不上线，不过它还是会出现在浮窗的词表里。
- 有少数网站的正文不是用普通段落写的，这种页面浮窗不会出来。
- 现在只能英译中。
